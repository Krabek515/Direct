# Direct

Расширение Chrome для управления маршрутизацией трафика вместе с V2RayTun. Утилита оптимизирует соединения: выбранные хосты направляются напрямую, минуя прокси.

Зелёная стрелка у вкладки означает прямое подключение. Серая — что трафик идёт через прокси. Язык окна переключается справа сверху, EN / RU.

## Как пользоваться

- Нажми на значок и добавь открытый сайт в прямое подключение. Вместе с ним напрямую идут его поддомены и адреса, с которых страница берёт картинки и данные. Так эти запросы не расходуют прокси.
- Если сайт из-за настроек прокси не начинает открываться, вставь ссылку и нажми «Напрямую». Ждать страницу с ошибкой не нужно.
- Правый клик по ссылке, затем «Открыть напрямую».
- «Выключить расширение» возвращает Chrome к системным настройкам прокси.

## Установка

V2RayTun уже должен быть включён, в режиме прокси.

1. Дважды нажми `install.bat`. Он сам соберёт программу, которая читает порт V2RayTun, и разрешит Chrome её запускать. Если папку проекта перенесли, запусти `install.bat` ещё раз.
2. Откроется страница расширений. Включи режим разработчика и нажми «Загрузить распакованное». Укажи папку `extension`.
3. Если Chrome спросит доступ к сайтам, разреши. После обновления файлов нажми «Обновить» у Direct.
